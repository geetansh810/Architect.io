# Architect.io 🛠️📐
### Visual Backend Intelligence Platform

Architect.io is a revolutionary platform that allows developers to design, visualize, and generate full-stack MERN (MongoDB, Express, React, Node.js) applications using a node-based interface.

## 🚀 Key Features
- **Visual Builder**: Design your backend logic and database schema using an interactive node-based canvas.
- **Smart Code Generation**: Export production-ready Node.js/Express code based on your visual architecture.
- **Advanced Admin Dashboard**: High-granularity analytics with Radar Charts for geographical distribution (Country/State/City).
- **Secure Authentication**: JWT-protected routes with Email OTP Verification and automated location detection.
- **Modern UI**: A premium, dark-mode focused experience built with React, TailwindCSS, and Framer Motion.

## 📂 Repository Structure
- **/frontend**: React + Vite application featuring the visual builder and admin suite.
- **/backend**: Node.js + Express server handling authentication, generation, and analytics.

## 🛠️ Getting Started
1. Clone the repository.
2. Setup `.env` files in both `/frontend` and `/backend` (see READMEs in respective folders).
3. Run `npm install` in both directories.
4. Start development servers with `npm run dev`.
