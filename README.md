# Architect.io 🚀📐
### Visual Backend Intelligence & MERN Stack Generator

**Architect.io** is a powerful visual development platform that allows engineers to design, visualize, and generate production-ready MERN (MongoDB, Express, React, Node.js) applications using a sophisticated node-based interface.

---

## 🌟 Introduction
Architect.io bridges the gap between high-level architectural design and low-level code implementation. It empowers developers to build complex backend infrastructures visually and export them as clean, modular, and scalable codebases in seconds.

## 🏗️ Project Architecture

### 1. The Core Engine (Backend)
The backend is built with **Node.js** and **Express**, utilizing a **Modular Monolith** pattern:
- **Visual Parser**: Converts node-based JSON architectures into executable JavaScript services.
- **Auth & Security**: Implements JWT authentication with **Email OTP Verification** and silent geolocation detection.
- **Analytics Engine**: Uses custom Mongoose aggregation to track user growth and regional distribution.
- **Email Service**: Automated transactional emails (OTP & Welcome) via Nodemailer.

### 2. The User Interface (Frontend)
Built with **React** and **Vite**, the frontend focuses on a premium developer experience:
- **Visual Builder**: A high-performance canvas using `@xyflow/react` for designing logic flows.
- **Admin Dashboard**: A data-rich command center featuring **Radar Charts**, Area Charts, and real-time platform metrics.
- **Premium Aesthetics**: Fully responsive dark-mode UI powered by **TailwindCSS** and **Framer Motion**.

## 🚀 Key Features
- ✅ **6-Digit OTP Verification**: Secure email-based registration flow with attempt limiting.
- ✅ **Precision Geolocation**: Automated tracking of user Country, State/Region, and City.
- ✅ **Advanced Data Viz**: Multi-level geographical filtering (Radar Chart) for admin insights.
- ✅ **Code Generation**: Instant export of production-ready Express.js folders.
- ✅ **Seamless Navigation**: Smart CTAs that handle dynamic signup/login transitions.

## 🛠️ Tech Stack
- **Frontend**: React.js, Vite, TailwindCSS, Recharts, Framer Motion, Lucide Icons.
- **Backend**: Node.js, Express.js, MongoDB (Mongoose), JWT, Nodemailer, BcryptJS.
- **APIs**: Ipify & IP-API for geolocation services.
