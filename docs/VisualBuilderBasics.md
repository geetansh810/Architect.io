# Visual Builder Basics

The Architect.io canvas is where you design your backend architecture.

## The Canvas
- **Nodes**: Represent components of your backend (Entities, APIs, Auth, etc.).
- **Edges**: Represent relationships and logic flows between nodes.

## Entity Nodes
- Right-click or use the sidebar to add an Entity.
- Define fields like `name`, `email`, `price`.
- Specify data types and validation rules.

## Relationship Modeling
- Drag an edge from one Entity to another to create a relationship.
- Support for 1:1, 1:N, and N:M relationships.
- Automatically handles foreign keys in the generated code.
