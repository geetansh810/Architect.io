# Roadmap & Changelog

Architect.io maintains a **public roadmap** and **changelog** so you can see what's been shipped, what's in progress, and what's coming next.

## Accessing

- **Roadmap**: Navigate to `/roadmap` from the navigation bar.
- **Changelog**: Navigate to `/changelog` from the navigation bar.

---

## Public Roadmap

The roadmap is displayed as a **Kanban-style board** with four columns:

### Shipped ✅
Features that are released and live on the platform.

### In Progress 🔄
Features currently being built. Includes estimated delivery dates.

### Planned 📅
Confirmed for upcoming releases with target quarters.

### Considering 💡
Ideas being evaluated. **Community upvoting** helps prioritise these features.

### Upvoting

- Click the **Upvote** button on any non-shipped item to cast your vote.
- Votes are persisted in your browser's localStorage.
- You can only vote once per item.
- Items are sorted by vote count within each column.

### Category Filters

Filter the entire board by category tags:
Core, Code Gen, Auth, Canvas, Docs, Growth, Templates, Community, Collaboration, Integrations, Analytics, AI, DevOps, Sharing, Security.

---

## Changelog

The changelog displays every release in a **timeline format** with:

### Version Tags
- **Major Release** — Significant new features (e.g., v0.6.0)
- **Minor Release** — Enhancements and new capabilities (e.g., v0.5.5)
- **Patch** — Bug fixes and small improvements

### Change Types
Each release groups changes by type:
- 🟢 **New** — Brand new features
- 🔵 **Improved** — Enhancements to existing features
- 🟡 **Fixed** — Bug fixes

### Filtering
Filter releases by tag type (All, Major, Minor, Patches) using the tabs at the top.

### Expanding Details
The latest release is expanded by default. Click "Show X changes" to expand any other release.
