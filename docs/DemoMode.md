# Demo Mode

Try the full Architect.io canvas experience **without creating an account**.

## How to Access

1. Visit the landing page.
2. Click **"Try Live Demo"** in the hero section.
3. You'll be loaded into a pre-configured MERN architecture canvas.

## What's Included

| Feature                  | Available in Demo? |
| ------------------------ | ------------------ |
| Full canvas (pan, zoom)  | ✅                 |
| All 16 node types        | ✅                 |
| Add / remove nodes       | ✅                 |
| Connect nodes (edges)    | ✅                 |
| Properties panel         | ✅                 |
| Code preview modal       | ✅                 |
| README / Docs preview    | ✅                 |
| Canvas minimap           | ✅                 |
| Save project             | 🔒 Account needed |
| Export code (ZIP)         | 🔒 Account needed |
| Multiple projects        | 🔒 Account needed |
| Project history          | 🔒 Account needed |

## Demo Architecture

The demo pre-loads an **8-node MERN architecture** including:
- API Gateway
- Auth Service (JWT)
- User Entity
- Product Entity
- MongoDB Database
- Redis Cache
- Logic Worker
- Mail Service

## Gate Actions

When you try to **save** or **export** in demo mode, a gentle modal appears:
- Explains what you'll get with a free account
- Links to sign up / log in
- Does not interrupt your workflow

## Inactivity Nudge

After **20 minutes** of inactivity, a subtle notification encourages you to create an account to preserve your work. It can be dismissed.

## Browser Persistence

- Demo progress is stored in your **browser state** (React context).
- Refreshing or closing the tab **will lose your changes**.
- Create a free account to save permanently.

## Transitioning to a Full Account

1. Click **"Create Account"** in the demo banner or gate modal.
2. Sign up with email + OTP verification.
3. Your demo architecture won't carry over — start fresh with saved projects.
