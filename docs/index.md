# Architect.io Documentation Index

Welcome to the official documentation for **Architect.io** — a visual backend development platform.

## Quick Start

- **Try the demo**: Visit the landing page and click "Try Live Demo" — no account needed.
- **Create an account**: Sign up with your email using our 6-digit OTP verification.
- **Start building**: Launch the visual canvas and drag nodes to design your architecture.
