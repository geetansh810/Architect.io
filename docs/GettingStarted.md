# Getting Started

Follow these steps to build your first backend with Architect.io.

## 1. Setup

Clone the repository and install dependencies:

```bash
git clone https://github.com/geetansh810/backendflow.git
cd backendflow/frontend && npm install
cd ../backend && npm install
```

## 2. Running Locally

Start the development servers:

**Backend:**
```bash
cd backend
npm run dev
```

**Frontend:**
```bash
cd frontend
npm run dev
```

## 3. Creating Your First Project

1. Open the dashboard.
2. Click **"New Project"**.
3. Drag an **Entity Node** and an **API Node**.
4. Connect them.
5. Click **"Export Code"**.
